<objective>
Phase 2의 개별 구현을 end-to-end fake flow로 묶고, broad permission/full-library scan 회귀를 막는 guard를 추가한다. 실행 완료 시 summary에는 자동 검증과 Android/iOS 수동 smoke 결과를 분리해 기록한다.
</objective>

<user_story>
사용자로서 나는 Today에서 Scan으로 이동해 사진이나 파일을 선택하고, 진행/중복 skip/취소/완료 상태를 신뢰할 수 있어야 한다. 앱은 내가 선택하지 않은 사진첩이나 폴더를 스캔하지 않아야 한다.
</user_story>

<must_haves>
- SCAN-01: Today CTA와 Scan tab entry가 모두 검증된다.
- SCAN-02: fake picker가 사용자가 선택한 source만 반환하고 UI가 이를 사용한다.
- SCAN-03: progress, candidate placeholder, cancel이 flow test에서 검증된다.
- SCAN-04: duplicate skip count와 fingerprint cache behavior가 flow 수준에서 검증된다.
- D-14: native picker/platform 차이는 adapter 뒤에 머문다.
- D-16: completion은 Phase 3 handoff shell이고 review/save/report로 넘어가지 않는다.
- QUAL-01/02 supporting guard: server, cloud sync, broad permission, upload behavior를 추가하지 않는다.
</must_haves>

<truths>
- Phase 2는 local-only MVP 원칙을 유지한다.
- Native picker 실제 구현이 없더라도 fake adapter 기반으로 phase behavior는 완성으로 인정할 수 있다.
- iOS simulator blocker는 환경 이슈로 summary에 분리 기록한다.
</truths>

<context_decision_coverage>
- D-01: Flow test는 Scan tab idle start를 포함한다.
- D-02: Today CTA는 Scan tab 이동까지만 검증한다.
- D-04: Batch shell은 Phase 2에서 구현하고 OCR은 제외한다.
- D-05: Progress/cancel shell을 flow test에 포함한다.
- D-08: Partial success, skipped, failed, and unprocessed language is covered in flow or focused widget tests.
- D-09/D-10: Duplicate fingerprint skip을 cache와 UI summary 모두에서 검증한다.
- D-11: Repeat selection skip is verified at flow level with the same source identity/content signature.
- D-14: Platform-specific details are kept behind adapters.
- D-16: Completion shell is a Phase 3 handoff, not candidate review.
</context_decision_coverage>
