## 변경 사항

- `GuidedScanController.retryFailed()`를 추가해 성공 항목은 다시 처리하지 않고 실패한 `ScanItem`과 retryable source handle만 다시 처리합니다.
- 재시도 중 다시 실패해도 기존 성공 개수와 후보가 유지되도록 처리 상태를 보존했습니다.
- `reset()`과 `dispose()`가 retained staged refs와 retryable source handles를 picker `release()`로 정리합니다.
- Scan 시작 화면에 `폴더에서 찾기`를 추가하고, 직접 고른 폴더의 바로 안쪽 이미지만 확인한다는 copy를 노출했습니다.
- 부분 성공 화면에서 실패 개수, 남은 항목 재시도, 확인한 후보 보기, 다시 선택을 모두 제공합니다.
- 후보 저장/수동 저장 실패 시 폼을 유지하고 `저장하지 못했어요. 다시 시도해 주세요.` copy를 표시합니다.
- `CouponKeeperDependencies.production()`을 추가해 기본 앱 경로가 SQLite 저장소, SQLite fingerprint cache, app-internal image copy store, MethodChannel selected-source picker, MethodChannel OCR recognizer를 사용하도록 연결했습니다.
- `ScanScreen` 기본 경로에서 Phase 2 demo picker, fake OCR/copy store, in-memory repository/cache import를 제거했습니다.
