<objective>
Create the pure Dart OCR/candidate foundation that turns normalized OCR text into honest review candidates and a conservative discovery report.
</objective>

<user_story>
사용자로서 나는 앱이 쿠폰 이미지에서 읽은 내용을 자동 저장하지 않고, 믿을 수 있는 후보와 불확실한 항목을 구분해서 보여주기를 원한다.
</user_story>

<must_haves>
- OCR SDK types never leak into domain or presentation code.
- Unknown or low-confidence values are not invented or included in protected totals.
- Parser tests include Korean date, won value, brand/title, and barcode numeric fixtures.
- Candidate save readiness requires title or brand plus user-confirmed expiry.
</must_haves>

<threat_model>
| Threat | Severity | Mitigation |
|--------|----------|------------|
| T-03-01: Native OCR SDK types leak across layers and make tests platform-dependent | high | Normalize to `OcrTextResult`, `OcrTextBlock`, `OcrTextLine`, and nullable confidence in pure Dart. |
| T-03-02: Parser silently invents or auto-confirms wrong expiry/value | high | Preserve multiple expiry candidates, require explicit expiry confirmation, and test absent/ambiguous values. |
| T-03-03: Discovery report exaggerates protected value | high | Add a named high-confidence threshold and include only eligible value candidates in the total. |
</threat_model>
