# Research: Features

**Generated:** 2026-05-21
**Project:** Coupon Keeper

## Table Stakes

- Guided import from photos and downloads
- OCR candidate detection
- User confirmation before saving
- Local coupon/pass wallet
- Pass detail with large image and barcode
- Expiry reminders
- Manual registration fallback
- Used/expired states
- Local privacy posture with no server account

## Differentiators

- First scan discovery report that shows found candidates, expiring soon, possibly expired, and estimated protected value
- Free plan that still provides D-7/D-Day reminders
- Used coupon cleanup candidate flow without automatic deletion
- Contextual Pro gate tied to actual value moments
- Pass model that can later support membership, barcode, voucher, and ticket images

## Anti-Features

- First-launch full-library background scan
- Auto-saving OCR results without user confirmation
- Auto-deleting source images
- Ads in the free version
- Cloud sync before local trust is validated
- Wallet pass generation in MVP

## Notes

The product should feel less like a photo cleanup app and more like a calm money-saving wallet. The first value moment is not "OCR worked"; it is "I found something you might have lost."
