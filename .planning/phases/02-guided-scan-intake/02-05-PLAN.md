<objective>
Fix the Phase 2 UAT gap where repeated manual source selection in the default app path shows `확인한 항목 1개` instead of duplicate skip feedback.
</objective>

<user_story>
As a user re-checking the same selected coupon image, I want Coupon Keeper to tell me it skipped an already-checked item, so that I can trust it is not repeatedly processing the same source.
</user_story>

<gap>
UAT Test 4 reported: "반복 선택 후 완료 화면에 `확인한 항목 1개`만 보이고 `건너뛴 항목 1개` 또는 duplicate skip 문구가 보이지 않는다."

Root cause: `PhaseTwoDemoScanSourcePicker` currently generates a new source token per pick to keep Test 3 progress visible during repeated manual UAT. That prevents the default app path from ever selecting the same fingerprint twice, so duplicate detection cannot trigger.
</gap>

<must_haves>
- Repeating `다시 선택` -> `다운로드/파일에서 찾기` in the default app path must show duplicate skip feedback.
- The duplicate-only path must remain observable: progress state should show `이미 확인한 항목 1개는 건너뛰었어요` before completion, or completion must clearly show `건너뛴 항목 1개`.
- Test 3 must stay fixed: source selection must not jump directly to empty/completion without a visible progress shell.
- The fix must not add real OCR, real native picker permissions, fake discovered coupons, fake found counts, saved pass cards, or protected value.
</must_haves>
