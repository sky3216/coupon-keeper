## Vision

Coupon Keeper는 사진 정리 앱이 아니라, 사용자가 잊고 있던 현금성 이미지 자산을
찾아 만료 전에 쓰게 만드는 로컬 쿠폰 지갑이다.

첫 시장은 한국으로 둔다. 첫 검증은 사용자가 3,900원을 낼 만큼 "쿠폰 손실 방지"에
가치를 느끼는지 확인하는 것이다. 12개월 뒤 이상적인 상태는 Apple Wallet 또는
Google Wallet에 들어가지 못한 쿠폰, 교환권, 멤버십 바코드, 티켓 이미지를 로컬에서
찾아주는 `local pass finder`다.

## Accepted Scope

- 쿠폰/교환권 후보 자동 탐지
- 활성 쿠폰 5개 무료 관리
- 수동 등록
- 기본 만료 알림 1회
- 쿠폰 지갑에서 이미지와 바코드 바로 보기
- 사용 완료 처리
- 첫 스캔 리포트
- 예상 쿠폰 금액 표시
- 사용 완료 후 정리 후보
- Pro 3,900원 1회 구매
- Pro의 활성 쿠폰 무제한, 반복 알림, 정리 후보, 멤버십/바코드 등록

## Deferred to TODO

- Apple Wallet/Google Wallet 추가 기능
- 자주 가는 장소 기반 알림
- 무료 광고 수익화 재검토

## Not in Scope

- Wallet 대체 앱
- 서버 동기화
- 계정 로그인
- 클라우드 백업
- 자동 매장 위치 데이터베이스
- 백그라운드 GPS 기반 매장 자동 탐지
- 글로벌 다국어 OCR 전체 대응

## CEO Findings

- 제품 범위는 "사진 정리"가 아니라 "쿠폰 손실 방지"로 유지해야 한다.
- 무료 광고는 MVP에서 빼야 한다. 초기 신뢰와 권한 허용률이 광고 수익보다
  중요하다.
- 위치 알림은 좋은 Pro 확장 기능이지만 MVP에 넣으면 권한 요청이 너무 빨라진다.
- Wallet 추가 기능은 글로벌 메시지에 좋지만, 현재 차별점은 Wallet 생성이 아니라
  Wallet 밖의 이미지를 찾아주는 것이다.
