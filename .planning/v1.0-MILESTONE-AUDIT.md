# v1.0 Milestone Audit

## 판정

**상태:** `passed`

Coupon Keeper v1.0 MVP의 앱 코드 범위는 통과했다. 예전 감사에서 막혔던 Phase 4~7 미구현 gap과 production local adapter gap은 Phase 3.1~7에서 닫혔다. 현재 기본 앱 경로는 실제 selected-source picker, on-device OCR, SQLite 저장소, 앱 내부 이미지 사본, 로컬 알림, 공식 인앱결제 gateway를 사용한다.

스토어 콘솔 설정, 실제 sandbox 결제 승인, signing/provisioning은 앱 코드가 아니라 배포 운영 작업으로 남긴다.

## 남은 운영 작업

앱 코드 마일스톤은 통과했지만, 내부 배포 전 아래 운영 설정이 필요하다.

1. App Store Connect와 Google Play Console에 `COUPON_KEEPER_PRO_PRODUCT_ID`와 동일한 non-consumable 상품을 만든다.
2. iOS signing/provisioning과 Android signing key를 실제 배포 계정 기준으로 설정한다.
3. sandbox/internal tester 계정으로 실제 구매/복원 승인을 확인한다.
4. 내부 테스트 트랙에 업로드한 뒤 기기별 smoke test를 한 번 더 수행한다.
